# Проєктування симулятора

Дата: 2026-11-07. Етап 2 у роботі. Це специфікація майбутньої реалізації; описані модулі й каталог ще не створені.

## Межі MVP

Одна лабораторія, два режими, відкриті посудини. Ручні дії: перетягування, встановлення, відмірювання, переливання, перемішування, керування нагріванням і вимірювання температури. Немає універсальної кнопки проведення реакції.

Початкове обладнання: джерела готових розчинів, дві склянки, мірний посуд, нагрівач і термометр. Місткості й доступні порції — параметри ігрового обладнання, а не властивості речовин. Обладнання додається поступово.

Не моделюємо універсальну хімію, тиск, герметичні системи, вибухи, горіння, точний теплообмін, випаровування, pH чи довільні багатоступеневі рівноваги. Непідтримувані комбінації отримують повідомлення «Це поєднання не підтримується поточною моделлю».

## Одиниці та джерело стану

- Канонічні одиниці: mol, L, °C, s. Інтерфейс може показувати mL, перетворення виконується на межі UI.
- Єдине джерело стану — об’єкт MixtureState, що належить посудині. UI й анімації читають стан, не створюють власних копій кількостей.
- Стан: ідентифікатор, версія, об’єм розчину, температура, кількості розчинених компонентів і твердих продуктів.
- Для розчиненого компонента c = n / V. За нульового об’єму концентрація не визначена; осаду й газу молярність розчину не призначається.
- Усі числа мають бути скінченними; кількість і об’єм невід’ємні. Числові допуски задаються окремими іменованими константами з одиницями, їхні значення обираються й тестуються під час реалізації.
- Об’єми розчинів додаються; зміною об’єму через реакцію й об’ємом осаду нехтуємо. Це явно позначене навчальне спрощення, а не універсальний фізичний закон.
- Вода-розчинник не дублюється як витрачуваний реагент; вода, утворена реакцією, має обліковуватися окремо в результаті для перевірки балансу. Вона не збільшує об’єм за прийнятим спрощенням.
- Газ виходить із відкритої посудини й зберігається в журналі результату як кількість продукту. Візуальні бульбашки не додають і не віднімають молі.

## Обрана модель розчинів

Плануємо облік іонних компонентів для сильних електролітів. Пляшка має назву вихідної речовини, але її визначення задає склад розчину: наприклад, NaCl дає Na+ і Cl− у співвідношенні 1:1. Це дозволяє не втрачати сторонні іони та не вводити суперечливі «солі» після змішування.

Каталог міститиме атомний склад, заряд і фазу кожного компонента. Рушій працює зі скороченими іонними рівняннями; повне навчальне рівняння зберігається окремо для посібника. Потрібні перевірки атомного та зарядового балансу, включно з журналом виведених продуктів.

Дисоціація, кінетика й рівновага не обчислюються універсально. Для навчальних реакцій потрібна явно обмежена область застосування. Стехіометричне осадження до лімітуючого реагенту є наближенням: у реальності осадження залежить від концентрацій і рівноваги [S1]. Не дозволяти такому наближенню видавати результати для довільно розбавлених розчинів; діапазони потрібно обґрунтувати перед внесенням до каталогу.

## Моделі та контракти

| Запланована модель | Основні дані |
| --- | --- |
| SpeciesDefinition | id, українська назва, формула, атомний склад, заряд, фаза, джерела |
| StockSolutionDefinition | id, назва, іонний склад, вихідна концентрація, джерела й допустима область |
| EquipmentDefinition | id, місткість, підтримувані дії, сумісні зони |
| MixtureState | id, revision, volume_l, temperature_c, dissolved_moles, solid_moles |
| ReactionDefinition | id, reactants, products, conditions, visual_events, sources, simplifications |
| ReactionResult | витрачено/утворено, виведені продукти, зміна стану, події |
| LevelDefinition | id, обладнання, запаси, завдання, наступне відкриття |
| PlayerProgress | schema_version, discovered_reaction_ids, completed_level_ids, unlocks |

JSON перевіряється до створення типізованих об’єктів. Каталог і прогрес гравця фізично та логічно розділені. Назви полів тут — запропонований контракт, не твердження про наявний код.

## Передавання та реакція

1. Контролер перетворює ручну дію на запит доменної операції.
2. Перевіряються посудини, доступні кількості, місткість і актуальна revision.
3. Переливання однорідної рідини переносить об’єм і розчинені компоненти пропорційно. Осад не переноситься цією операцією: для нього потрібна окрема підтримувана дія.
4. Нова суміш перевіряється за каталогом. Неоднозначні кілька реакцій поза явно визначеним сценарієм повертають unsupported_combination; порядок JSON не визначає результат.
5. Після перевірки умов xi = min(n_i / nu_i) для витрачуваних реагентів. Перевіряється повний розрахований результат.
6. Переливання й реакція — послідовні атомарні операції: помилка реакції не скасовує вже коректно виконане переливання. Кожна окрема операція не залишає часткових змін.
7. Коміт реакції перевіряє revision, оновлює суміш і надсилає один reaction_applied із mode, level_id і унікальним ідентифікатором застосування.
8. Ефекти, посібник і кампанія слухають подію. Відкриття ідемпотентне; кампанія враховує лише події активного рівня в режимі кампанії.

## Нагрівання

Температура змінюється за окремою педагогічною моделлю з обмеженнями. Швидкість нагрівання є параметром ігрового обладнання, не теплофізичною властивістю речовини. Не моделювати приховане кипіння, тепло реакції або небезпечні ефекти без джерел.

Змішування різних температур потребує описаної моделі; перед її реалізацією визначити й перевірити припущення. Перший експеримент використовує однакову початкову температуру. Ціль нагріти до заданого показу в рівні є навчальним завданням; вона не додає вигаданої умови хімічній реакції.

## Перший експеримент: виділення CO2

Обрано взаємодію готового розчину гідрогенкарбонату натрію з хлоридною кислотою. Утворення CO2 підтверджене університетською демонстрацією [S2].

Навчальне рівняння: NaHCO3 + HCl → NaCl + CO2 + H2O.
Іонне рівняння для розрахунку: HCO3− + H+ → CO2 + H2O.

Механічна тестова задача, а не інструкція реального досліду: взяти 0,010 L кожного готового розчину з вихідною концентрацією 0,10 mol/L. У кожній порції по 0,001 mol потрібного реагенту; після змішування модель утворює 0,001 mol CO2 і стільки ж води. Початкові кількості — параметри навчального сценарію, не запозичений лабораторний протокол. Умови застосування мають бути перевірені до випуску каталогу.

Гравець ставить приймальну склянку, відміряє першу порцію, переливає другу, перемішує й спостерігає бульбашки. Крок перемішування — педагогічний тригер завершення підготовки, а не твердження, що фізична реакція чекає на команду. Нагрівання не потрібне. Немає вибуху, диму чи закритої посудини.

Перевірки: кількість продукту, випадок надлишку, нульовий реагент, переповнення, повторний callback, збереження сторонніх іонів і балансу атомів/заряду, одноразове відкриття.

## Попередній каталог із восьми кандидатів

Це список для перевірки й наповнення майбутнього JSON. Не всі умови та візуальні властивості вже підтверджені; кандидати не є готовими записами каталогу.

| ID | Скорочене рівняння | Джерело / що ще перевірити |
| --- | --- | --- |
| bicarbonate_acid | HCO3− + H+ → CO2 + H2O | S2; діапазон застосування й модель виходу газу |
| carbonate_acid | CO3²− + 2H+ → CO2 + H2O | S3; неповне підкислення й проміжний HCO3− не можна ігнорувати |
| silver_chloride | Ag+ + Cl− → AgCl(s) | S1; умова пересичення й область стехіометричного наближення |
| calcium_carbonate | Ca²+ + CO3²− → CaCO3(s) | S1; умови осадження й спрощення рівноваги |
| copper_hydroxide | Cu²+ + 2OH− → Cu(OH)2(s) | S4; діапазони, ефект і сторонні реакції |
| magnesium_hydroxide | Mg²+ + 2OH− → Mg(OH)2(s) | S1, S4; область осадження |
| iron_ii_hydroxide | Fe²+ + 2OH− → Fe(OH)2(s) | S4; подальше окиснення не включати мовчки |
| iron_iii_hydroxide | Fe³+ + 3OH− → Fe(OH)3(s) | Кандидат: потрібне окреме підтвердження рівняння, умов і ефекту перед прийняттям |

Для кожного запису до реалізації потрібні джерела, збалансоване рівняння, допустимі умови, спрощення, ефекти й очікувані результати тестів. Неперевірений кандидат може бути замінений. На цьому етапі не задаємо числові константи розчинності, кольори або температурні пороги без джерел.

## П’ять рівнів

1. Вимірювання, посуд і переливання: зберегти задану кількість розчину без переповнення.
2. Перший експеримент із CO2: виконати послідовність і спостерігати результат.
3. Лімітуючий реагент: порівняти задані кількості й пояснити залишок.
4. Нагрівач і термометр: установити обладнання й досягти навчальної цілі температури без вигаданої хімічної умови.
5. Самостійний багатокроковий експеримент із перевіреного каталогу.

Конкретні цілі, інвентар і відкриття стануть даними рівнів. Пісочниця використовує той самий рушій, але не завершує ці завдання.

- [S4 — RSC/Nuffield, Microscale reactions of positive ions with sodium hydroxide](https://edu.rsc.org/experiments/microscale-reactions-of-positive-ions-with-sodium-hydroxide/757.article): гідроксиди й обмеження реакцій. Повна сторінка недоступна (405); витяг підтверджує Cu, Fe(II), Mg, але повні дані треба звірити.

Етап 2 не завершено: перевірити повні джерела для всіх восьми реакцій, область застосування, вибір вихідних розчинів і модель змішування температур. До завершення цього перегляду не створювати каталог із позначкою «перевірений».
